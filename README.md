# Formación360 - Prototipo Frontend de Baja Fidelidad

Este proyecto es un prototipo frontend de baja fidelidad para el Sistema de Gestión de Aprendizaje Formación360. Incluye pantallas estáticas básicas para visualizar elementos clave de la interfaz y el flujo de navegación.

## Características

- Pantalla de inicio de sesión con campos para usuario/email y contraseña.
- Pantalla de panel de control con secciones de marcador de posición: Mis Cursos, Mi Progreso, Ayuda (Chatbot), Configuración.
- Flujo de navegación simple entre la pantalla de inicio de sesión y el panel de control.
- Diseño responsivo con estilo moderno.

## Cómo empezar

Abra el archivo `index.html` en un navegador web para comenzar a usar el prototipo.

## Control de versiones

Este proyecto utiliza Git para el control de versiones. Asegúrese de realizar commits regularmente.

## Linters

Este proyecto incluye configuración para los siguientes linters:

- ESLint para JavaScript (uso mínimo)
- Stylelint para CSS

### Ejecutar Linters

Instale las dependencias (si usa npm):

```bash
npm install
```

Ejecute ESLint:

```bash
npx eslint .
```

Ejecute Stylelint:

```bash
npx stylelint "**/*.css"
```
